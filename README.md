# 🚲 Pure Cycles

**Ride Your Way. Explore Your World.**

Pure Cycles is a bicycle website created using HTML and CSS. It showcases different types of bicycles, cycling accessories, and information about the brand through a simple, user-friendly website.

## 📌 Project Overview

The main purpose of this project is to create a website for a bicycle store where users can explore bicycle collections, discover useful accessories, and learn more about Pure Cycles.

## ✨ Features

- **Home Page:** Introduces Pure Cycles and highlights its offerings.
- **Bikes Page:** Showcases different categories of bicycles, including city bikes, mountain bikes, and electric bikes.
- **Accessories Page:** Displays cycling accessories such as helmets, water bottles, and bike lights.
- **About Us Page:** Provides information about the brand and its cycling philosophy.
- **Visual Content:** Includes bicycle images and video files.
- **Navigation Menu:** Provides links to navigate between website pages.
- **CSS Styling:** Adds layout, colors, and visual design to the website.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Images and video assets

## 🚀 How to Run the Project

1. Download or extract the project ZIP file.
2. Open the project folder.
3. Locate `file.html`.
4. Double-click `file.html` to open the website in your web browser.
5. Use the navigation menu to explore the different pages.

**Note:** Keep the HTML, CSS, image, and video files in their original folder structure so that linked resources can load correctly.
